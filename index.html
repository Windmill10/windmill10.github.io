Research

Diversity loss under reinforcement learning

NTHU DATALAB, advised by Prof. Shan-Hung WuMar 2025 – present

Our project aims to make LLMs write more engaging stories, and I am responsible for the RL part. My first attempt, a reward model trained on reader votes from Wattpad, performed no better than chance. An analysis showed that 89% of the variance in vote rate lay between stories, reflecting author, genre and popularity. I next asked why LLMs overuse certain words. Comparing checkpoints of OLMo-2 7B across its training stages, I found that this vocabulary is absent in the base model and enters with the supervised fine-tuning data.

I therefore trained the Qwen2.5-1.5B base model with RL on verifiable rewards from math, coding and instruction-following tasks alone, with no fine-tuning data and no reward for stories. The model learned to write valid stories, and an LLM judge rated them on par with the official Instruct model, but their openings became concentrated. To explain this I extended a known policy-gradient analysis. When a reward cannot distinguish between outputs that are equally correct, the output that is already more probable receives the larger update. The loss of diversity under RL is the problem I most want to work on.

SSD-based KV-cache offloading for multi-agent LLM serving

NTHU syslab, advised by Prof. Yun-Chih ChenFeb 2026 – present

In multi-agent LLM serving, KV cache that exceeds GPU memory is offloaded to SSDs, and because an SSD endures a limited number of writes, offloading shortens its life. I studied one month of real Claude Code and Codex traffic, 1,820 sessions and about 190,000 requests, and found that much of the KV cache written to the SSD is never read again. The dead data comes from prefixes invalidated when an agent compacts its context, from unfilled tail blocks that the next request rewrites, and from data left behind when a session ends.

I designed write-back DRAM staging, which holds new KV cache in memory so that a write can be cancelled once the data is known to be dead, and combined it with session-grouped placement on ZNS SSDs, which lets a session's data expire together. I was responsible for the problem characterization and most of the core method. My co-authors built the simulator and ran part of the experiments.
