Research

Diversity loss under reinforcement learning

NTHU DATALAB, advised by Prof. Shan-Hung WuMar 2025 – present

I trained the Qwen2.5-1.5B base model with reinforcement learning on verifiable rewards alone, using math, coding and instruction-following tasks and no supervised fine-tuning data. Stories were never rewarded, yet the model learned to produce valid ones, and an LLM judge rated them on par with the official Instruct model. Their openings, however, became concentrated. To explain this, I extended a known policy-gradient analysis. When a reward cannot distinguish between outputs that are equally correct, the output that is already more probable receives the larger update.

SSD-based KV-cache offloading for multi-agent LLM serving

NTHU syslab, advised by Prof. Yun-Chih ChenFeb 2026 – present

I studied multi-agent LLM serving, in which KV cache that exceeds GPU memory is offloaded to SSDs whose write endurance is limited. I analyzed one month of Claude Code and Codex traces and found that much of the offloaded KV cache is never read again. Based on this, I designed write-back DRAM staging, which cancels such writes before they reach the SSD, and session-grouped placement on ZNS SSDs, which lets a session's data expire together. The simulator and part of the experiments were built by my co-authors.
