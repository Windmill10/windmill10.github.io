Research

Diversity loss under reinforcement learning

NTHU DATALAB, advised by Prof. Shan-Hung WuMar 2025 – present

I trained the Qwen2.5-1.5B base model with reinforcement learning on verifiable rewards alone, with no supervised fine-tuning data. The model learned to produce valid stories that an LLM judge rated on par with the official Instruct model, but their openings became concentrated. To explain this, I extended a known policy-gradient analysis.

SSD-based KV-cache offloading for multi-agent LLM serving

NTHU syslab, advised by Prof. Yun-Chih ChenFeb 2026 – present

When KV cache exceeds GPU memory it is offloaded to SSDs, whose write endurance is limited. In one month of Claude Code and Codex traces I found that much of the offloaded KV cache is never read again. I designed write-back DRAM staging, which cancels such writes before they reach the SSD, and session-grouped placement on ZNS SSDs. The simulator was built by my co-authors.
